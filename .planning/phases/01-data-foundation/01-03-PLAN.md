Create src/scheduler/jobs.py:
- async def scraping_job(session_factory: async_sessionmaker, client: TelegramClient):
  1. Create async session from factory
  2. Create ChannelRepository(session) and PostRepository(session)
  3. Fetch active channels via channel_repo.get_active_channels()
  4. For each channel (sequential per CONTEXT decision):
     a. Create ScraperService(client)
     b. Call service.scrape_channel(channel.username, max_posts=settings.scraper.max_posts)
     c. If posts found: call post_repo.upsert_posts(channel.id, posts)
     d. Call channel_repo.mark_scraped(channel.id)
     e. If ChannelNotFoundError: call channel_repo.mark_error(channel.id, "Channel not found or private")
     f. If other exception: log error, continue to next channel
  5. Commit session (or per-channel commit with rollback on error)
  6. Log summary: "Scraped {N} channels, inserted {M} new posts"

- async def create_scheduler(settings: Settings, session_factory, client) -> AsyncIOScheduler:
  - Create AsyncIOScheduler
  - Add job: scraping_job with IntervalTrigger(minutes=settings.scheduler.interval_minutes)
  - misfire_grace_time=60 (allow 1 min grace)
  - coalesce=True (don't queue missed runs)

Create src/main.py — application entry point:
- async def main():
  1. Load Settings from config.toml + env vars
  2. Create async engine from settings.database.url
  3. Run Alembic migrations on startup (optional: only in dev mode)
  4. Create async_sessionmaker
  5. Create TelegramClient from settings
  6. Create and start AsyncIOScheduler with scraping_job
  7. Log "Bot started, scraping every {N} minutes"
  8. Run forever: await asyncio.Event().wait() (or try/except KeyboardInterrupt)
  9. On shutdown: scheduler.shutdown(), await client.close(), dispose engine

- if __name__ == "__main__": asyncio.run(main())
