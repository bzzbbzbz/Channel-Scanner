# Telegram Channel Monitor Bot

## What This Is

Telegram-бот для мониторинга каналов. Пользователь выбирает каналы для отслеживания, настраивает формат сводок (первые 200 символов, краткий пересказ, полная), частоту уведомлений (сразу, раз в час/сутки), фильтры по темам и ключевым словам. Бот парсит посты через t.me/s/*, хранит в PostgreSQL, по расписанию отправляет отчёты. Есть предустановленные подборки каналов по темам, inline-кнопки для управления подписками.

## Core Value

Пользователь получает релевантные сводки из отслеживаемых Telegram-каналов в одном месте — без необходимости вручную просматривать каждый канал.

### Out of Scope

- Чтение закрытых/приватных каналов — t.me/s/* работает только для публичных
- Отправка сообщений от имени пользователя — только чтение
- Медиа-контент (фото, видео) — v1 только текст
- Множественные языки интерфейса — v1 русский
- Web-интерфейс — v1 только Telegram-бот
- Голосовые/аудио уведомления

## Context

- Существует прототип скилла telegram-search (Python, requests + BeautifulSoup), парсящий t.me/s/* — его архитектуру можно переиспользовать
- Парсинг через веб-интерфейс Telegram (t.me/s/channel) не требует API-ключей и не блокируется
- Для LLM-пересказов нужен доступ к LLM API (OpenAI/локальная модель)
- Telegram Bot API для взаимодействия с пользователями
- Python-экосистема — asyncio, aiogram/telebot, APScheduler/cron

## Constraints

- **Парсинг**: Только публичные каналы через t.me/s/* — нет доступа к приватным
- **Tech stack**: Python + PostgreSQL — согласовано
- **LLM**: Требуется внешний LLM API для генерации пересказов
- **Rate limiting**: t.me может ограничивать частоту запросов — нужна обработка 429
- **Хостинг**: Должен работать на VPS с постоянным запуском (cron/ scheduler)
