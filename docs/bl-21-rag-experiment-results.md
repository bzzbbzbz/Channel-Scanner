# BL-21: результаты изолированных экспериментов RAG

Дата: 2026-08-12. Ветка: `feature/bl-21-rag-quality-experiments`.

## Условия

- 100 вручную размеченных вопросов: 70 для выбора варианта и 30 независимых для проверки.
- Категории: 50 технических, 20 разговорных, 15 точных и 15 без подтверждённого ответа.
- Production, production БД, индекс и контейнеры не изменялись.
- В отчётах, этой сводке и Git нет вопросов, текстов постов, ответов модели и ключей.

## Независимая проверка

Метрики ниже относятся к 25 вопросам с подтверждённым ответом. Пять вопросов без ответа оценены отдельно.

| Вариант | Recall@5 | MRR | nDCG@5 | Верных отказов / ложных выдач | Решение |
|---|---:|---:|---:|---:|---|
| Векторный поиск без инструкции | 0.860 | 0.721 | 0.753 | 4 / 1 | исходная точка |
| Векторный поиск с инструкцией | 0.880 | 0.748 | 0.770 | 5 / 0 | лучшая базовая настройка |
| Смешанный поиск, RRF с BM25 x2 | 0.780 | 0.730 | 0.728 | 2 / 3 | отклонён: регрессия |
| Инструкция + Cohere Rerank 4 Pro, 20 постов | **0.940** | **0.873** | **0.881** | **5 / 0** | рекомендуется к отдельному рассмотрению для production |

Реранкер улучшил instructed vector baseline на `+0.060 Recall@5`, `+0.125 MRR` и `+0.111 nDCG@5`, не добавив ложных выдач. На development-подвыборке варианты с 20 и 30 кандидатами дали одинаковое качество, поэтому для независимой проверки выбран более экономный пул из 20.

## Цена и задержка

- Стоимость полной проверки реранкера: `$0.425025`: `$0.425` за 170 запросов к реранкеру и `$0.000025` за эмбеддинги вопросов. Это ниже разрешённого предела `$0.50`.
- В изолированной среде медианная задержка полного поиска выросла с 874 до 1 482 мс. Медиана времени реранкера — 524 мс.
- Эти значения — доказательство для выбора следующего шага, а не обещание production-задержки; перед включением нужны отдельные нагрузочные проверки.

## Вывод и границы

Лучший кандидат для отдельной production-задачи: существующий векторный поиск по всем представлениям с фиксированной инструкцией к запросу, затем Cohere Rerank 4 Pro по максимум 20 уже найденным каноническим публичным постам.

BL-21 не включает автоматический выпуск. Перед ним нужны безопасный флаг, ограниченный тестовый режим, измерение стоимости и задержки на рабочем окружении, проверка ссылок на первоисточники и возможность мгновенного отката. Проверка по фрагментам постов сознательно отложена: в снимке недостаточно фрагментных представлений для корректного сравнения.

Локальные content-free JSON-отчёты находятся только в игнорируемом `.data-experiment/experiments/`. Один уже созданный отчёт реранкера ошибочно записал старый общий лимит `$1`; фактическое ограничение было `$0.50`, а код для будущих запусков записывает правильный лимит.
